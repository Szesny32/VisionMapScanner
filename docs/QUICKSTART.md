# Installation

## 1.ROS-TCP-Endpoint
```
cd ~/ros2_ws/src
git clone -b main-ros2 https://github.com/Unity-Technologies/ROS-TCP-Endpoint.git
cd ~/ros2_ws
colcon build --packages-select ros_tcp_endpoint
source install/setup.bash
```
## 2. Activate scripts
```
chmod +x activate.sh
./activate.sh
```
